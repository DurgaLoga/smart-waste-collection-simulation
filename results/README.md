# Simulation Results

These are original outputs from the Smart Waste Collection simulation.

- `simulation_base_summary.csv`: aggregate statistics for the baseline threshold-8 policy (1,000 runs, 365 days each).
- `simulation_base_run_summary.csv`: one row per simulation run with collection and fullness statistics.
- `simulation_RV1_accumulation_occurrence.csv`: estimated conditional probabilities of an accumulation event.
- `simulation_RV2_increase_magnitude.csv`: estimated conditional probabilities of increase magnitude.

The detailed 365,000-row `simulation_base_results.csv` is intentionally excluded to keep the repository concise. These baseline outputs do not contain threshold-6 or threshold-10 scenario comparisons or sensitivity results.
