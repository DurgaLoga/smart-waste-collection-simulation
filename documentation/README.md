# Smart Waste Collection — Project Documentation

This folder contains the academic project report and presentation
for the Smart Waste Collection Monte Carlo Simulation project.

## Documents

- SmartWasteCollection_Presentation.pdf — Project presentation
- Smart_Waste_Collection_Project.pdf — Detailed project report

The project investigates smart waste collection policies using
historical sensor observations, probability modeling, Monte Carlo
simulation, and scenario analysis.

Refer to the repository's main README for the project overview,
methodology, findings, and implementation details.
