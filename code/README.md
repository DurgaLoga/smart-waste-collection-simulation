# Smart Waste Collection — Analytical Code

These are the original project notebooks with standardized filenames and cleared execution outputs. The analytical code has not been modified or re-executed.

Run in this order: `data_audit.py`, `01_data_understanding.ipynb` (exploration), `02_data_preparation.ipynb`, `03_random_variable_preparation.ipynb`, `04_simulation_model.ipynb`, `05_scenario_sensitivity_analysis.ipynb`.

**File paths:** The original code reads and writes CSV/JSON files using relative paths. To reproduce the workflow without editing paths, run from a working directory containing the input JSON and generated CSV files (or adjust paths to your local layout).

Dependencies: `pandas`, `numpy`, `matplotlib`, `scipy`, Jupyter. Source dataset and derived CSVs are not included in this code-only archive.
